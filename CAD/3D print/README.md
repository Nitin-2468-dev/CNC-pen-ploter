## Print Recommendations

| Setting      | Value               |
| ------------ | ------------------- |
| Material     | PLA / PETG          |
| Layer Height | 0.20 mm             |
| Infill       | 20–30%              |
| Supports     | Only where required |
| Nozzle       | 0.4 mm              |

PETG is recommended for improved durability, though PLA is sufficient for most indoor use.
